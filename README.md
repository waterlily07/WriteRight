# WriteRight

A lightweight essay-writing workspace that combines a prompt generator, a distraction-free editor, and a way to turn finished writing into shareable text posters — with Spotify integration so you can pair your writing with the music that shaped it.

## Why I built it

I wanted to experiment with building something that solves a problem I actually encounter as a student: having a simple space to work on essays without unnecessary complexity — one that also captures the mood behind the writing, not just the words.

## Features
Prompt generator — get essay prompts to kickstart writing when you're stuck on where to start
Built-in editor — a clean, focused space to draft and organize essays without distractions
Text poster creator — turn finished excerpts or full pieces into shareable visual posters
Spotify integration — connect your Spotify account to pair your writing/posters with a track, so the music you were writing to becomes part of the piece

## Built with
HTML
CSS
JavaScript

## What I learned

Building this project helped me understand how the different parts of a web application work together — particularly connecting a third-party API (Spotify) to a front-end project, handling user input across multiple linked features (prompt → editor → poster), and managing state so that what's written in the editor flows correctly into the poster output.

It also made me think more about the difference between making something technically work and making it useful for an actual user — a prompt generator is only helpful if the prompts feel worth writing about, and a poster feature is only worth having if sharing your writing actually feels satisfying.

## Future improvements
Add the ability to save and revisit past drafts instead of starting fresh each time
Let users customise poster templates (fonts, colours, layouts) instead of one fixed style
Expand prompt generation to let users pick a theme or mood, rather than fully random prompts
Getting started

Clone the repository and open the project locally in a browser.

If you're using the Spotify integration, you'll need to set up a Spotify Developer app and add your own Client ID (and Client Secret, if the flow requires it) to connect your account.
